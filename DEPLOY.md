# Deployment Guide (VPS)

Target layout on the server:

```
/opt/casino-platform/
  .env.production          # secrets (never commit)
  backend/
  frontend/build/          # generated by deploy
  database/
  game-engine/
  deploy.sh
```

## Prerequisites

- Ubuntu 22.04+ VPS with root SSH
- DNS **A record** for your domain → VPS public IP
- Local machine with `rsync` + `ssh`

Default domain in scripts: `reelx.lazapee.ph`  
Default IP in `push-to-vps.sh`: `188.166.250.245` (override with argument)

## 1. Create production env (on your laptop)

```bash
cp .env.production.example .env.production
nano .env.production
```

Set at least:

| Variable | Notes |
|----------|--------|
| `DB_PASSWORD` | Strong password |
| `JWT_SECRET` | `openssl rand -hex 32` |
| `JWT_REFRESH_SECRET` | `openssl rand -hex 32` |
| `REDIS_PASSWORD` | Strong password |
| `DOMAIN` / `FRONTEND_URL` / `VITE_*` | Your real domain |
| `XENDIT_*` | Optional until payments go live |

## 2. First deploy (from laptop)

```bash
chmod +x push-to-vps.sh deploy.sh
./push-to-vps.sh YOUR_VPS_IP
```

This will:

1. `rsync` the project to `/opt/casino-platform`
2. Install Node, MySQL, Redis, Nginx, Certbot, PM2
3. Create DB + run migrations + seed
4. Build frontend with `VITE_API_URL=https://DOMAIN/api`
5. Start backend via PM2
6. Configure Nginx (+ Let’s Encrypt if DNS is ready)

## 3. SSL

If Certbot failed (DNS not ready yet):

```bash
ssh root@YOUR_VPS_IP
certbot --nginx -d reelx.lazapee.ph
```

## 4. Updates

**Full re-deploy (same as first push):**
```bash
./push-to-vps.sh YOUR_VPS_IP
```

**Sync code only (no install):**
```bash
./push-to-vps.sh YOUR_VPS_IP --sync-only
ssh root@YOUR_VPS_IP 'cd /opt/casino-platform && bash deploy.sh'
```

**Quick update via `update.sh`** (password SSH + optional local frontend build):
```bash
./update.sh all          # frontend + backend + seed
./update.sh frontend     # frontend only
./update.sh backend      # backend only
```

## 5. Verify

```bash
curl -s https://YOUR_DOMAIN/health
API_URL=https://YOUR_DOMAIN/api node scripts/smoke-test.js
```

Demo logins (after seed):

- Admin: `admin@casino.com` / `admin123`
- Player: `player@casino.com` / `player123`

## 6. Ops commands (on VPS)

```bash
pm2 status
pm2 logs casino-backend --lines 100
pm2 restart casino-backend
nginx -t && systemctl reload nginx
mysql -u casino -p casino_platform
```

## 7. Common issues

| Symptom | Fix |
|---------|-----|
| Health returns SPA HTML | Ensure `/health` location exists (fixed in current `deploy.sh`) |
| CORS errors | `FRONTEND_URL=https://YOUR_DOMAIN` in `.env.production` |
| Login 500 | JWT secrets missing or MySQL unreachable — check `pm2 logs` |
| Certbot fail | Point DNS A record at VPS, wait for propagation, re-run certbot |
| Port wrong | `PORT=3020` in `.env.production`; Nginx proxies to that port |
| Payments fail | Set `XENDIT_*` and webhook URL `https://DOMAIN/webhooks/xendit` |

## 8. GitHub Actions (optional)

`.github/workflows/ci-cd.yml` deploys on push to `main` when secrets are set:

- `VPS_HOST`, `VPS_USER`, `VPS_SSH_KEY`, `VPS_PORT`
- `VITE_API_URL`, `VITE_SOCKET_URL`

## 9. CI/CD (GitHub Actions)

On every **push to `main`**:

1. Run backend + frontend tests + game-engine check  
2. Rsync code to the VPS  
3. Run migrations / rebuild frontend / restart PM2 **only for changed areas**  
4. Health-check the API  

### Required GitHub secrets

Repo → **Settings → Secrets and variables → Actions**:

| Secret | Example | Required |
|--------|---------|----------|
| `VPS_HOST` | `188.166.250.245` | Yes |
| `VPS_USER` | `root` | Yes |
| `VPS_SSH_KEY` | private key PEM contents | Yes |
| `VPS_PORT` | `22` | No (default 22) |
| `VPS_APP_DIR` | `/opt/casino-platform` | No |
| `DOMAIN` | `reelx.lazapee.ph` | No |
| `VITE_API_URL` | `https://reelx.lazapee.ph/api` | Recommended |
| `VITE_SOCKET_URL` | `https://reelx.lazapee.ph` | Recommended |

### GitHub Environment

Create environment **`production`** (Settings → Environments) so deploy needs approval if you want.

### Manual deploy from Actions

**Actions → CI/CD Pipeline → Run workflow** → choose mode: `all` / `frontend` / `backend` / `database` / `skip`.

### SSH key setup (one-time)

```bash
# On your laptop
ssh-keygen -t ed25519 -C "github-actions-deploy" -f ./gha_deploy -N ""
# Install public key on VPS
ssh-copy-id -i ./gha_deploy.pub root@YOUR_VPS_IP
# Put PRIVATE key contents into GitHub secret VPS_SSH_KEY
cat ./gha_deploy
```

Server still needs `/opt/casino-platform/.env.production` (never commit secrets).
