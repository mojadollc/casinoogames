## Image Specifications

| Property | Value |
|----------|-------|
| Format | PNG (transparent) or WebP |
| Size | 256x256px recommended |
| File names | Lowercase: wild.png, scatter.png, etc. |
| Max file size | ~50KB per image |

---

## How It Works

1. When a game loads, it checks `/assets/slots/{game-slug}/` for images
2. If `wild.png` exists → displays the image
3. If `wild.png` doesn't exist → displays the emoji fallback
4. Works independently for each symbol

---

## Example: Add Tiger Image to Fortune Tiger

```bash
cd frontend/public/assets/slots/fortune-tiger

# Add your custom tiger artwork
cp ~/Downloads/my-tiger-art.png wild.png

# Rebuild
cd ../../..
npm run build
```

The Fortune Tiger game will now show your custom tiger image instead of 🐅.
